# Classic Roblox LAN — milestone 0.1

Независимая игровая реконструкция, визуальный ориентир — Roblox 2012. Не официальный клиент, не подключается к Roblox, не использует Roblox-аккаунты. Код написан заново. Оригинальные карты и защищённые ресурсы не включены.

## Скачать на телефоне

1. Откройте **Actions → Build and verify** в этом репозитории.
2. Выберите последний **успешный** запуск. Если он красный, APK этого запуска не готов.
3. Внизу, **Artifacts → roblox-classic-android.apk**. GitHub потребует вход; загрузится ZIP с APK внутри.
4. Распакуйте ZIP и установите APK, разрешив установку из выбранного файлового менеджера.
5. **Зарегистрировать аккаунт**: имя 3–20 латинских букв/цифр/подчёркиваний, пароль от 6 символов.
6. **Настройки → Enable AI Players → Enable Anyway → 1 бот → Назад**.
7. **ИГРАТЬ ОФЛАЙН**. ПК и интернет для игры не нужны.

Круглый полупрозрачный джойстик слева — движение относительно камеры (включая диагонали), круглая кнопка со стрелкой справа — прыжок. Можно одновременно двигаться, прыгать и поворачивать камеру. Проведите по свободной части экрана для поворота камеры. Подойдите к лестнице перед площадкой и двигайтесь к ней для подъёма. Обратное движение спускает по лестнице. Chat открывает ввод. Menu → Leave Game завершает сессию.

## Два телефона через Wi-Fi

- Одна версия APK, разные имена локальных аккаунтов.
- Телефон 1: **СОЗДАТЬ LAN ИГРУ**. Оставьте приложение открытым.
- Телефон 2: **СЕРВЕРЫ В WI-FI → ReVerfyx Server → PLAY**.
- Без интернета работает, но оба устройства должны находиться в одной локальной сети.
- Если роутер блокирует broadcast, используйте DIRECT CONNECT и локальный IP первого телефона, TCP 53640. При изоляции Wi-Fi клиентов прямое соединение также не заработает.
- Сервер не имеет фонового Android Service: для первой версии держите хост на экране, без блокировки телефона.

## ПК-сервер

Скачайте соответствующий архив из Actions. Требуется установленная Java 17 (runtime не включён).

Windows: `server\bin\server.bat 1 ru`

Linux: `chmod +x server/bin/server && server/bin/server 1 ru`

Аргументы: количество ботов 0–16, язык `en`, `ru`, `de`, `es`, `fr`, `pt`, `pl`.
Разрешите TCP 53640 и UDP 53641 в брандмауэре **для частной сети**. ПК-сервер использует тот же core, что и Android-хост.

Экран входа/регистрации выполнен по предоставленному референсу раннего Roblox Mobile: голубые лучи, зелёный холм, контурный логотип и белые поля. Фон и надпись нарисованы заново средствами Android Canvas; это не вставленный скриншот. Вход — в портретной ориентации, игра — в альбомной.

## Что реализовано

- Native Android Activity + OpenGL ES 1.1, настоящий 3D-мир.
- OFFLINE / Android HOST / JOIN / headless PC server.
- R6: шесть частей, цилиндрическая видимая голова, лицо, ходьба/прыжок/падение/лестница/упрощённая смерть.
- Оригинальная тестовая Baseplate из Parts разного размера, spawn, препятствия, верхняя площадка и лестница.
- Гравитация, статические AABB-столкновения, прыжок, climb и respawn.
- Авторский граф навигации, поиск пути, бот действительно поднимается и выходит с лестницы.
- Тестовый цикл LOBBY → PREPARE → FLASH FLOOD → SURVIVORS → RETURN. Это **не полная Natural Disaster Survival**.
- Русский/английский основной UI; короткие CLASSIC-ответы на семи языках, команды follow/up, память из шести сообщений.
- Локальные аккаунты: UUID, соль, PBKDF2-HMAC-SHA1, 120000 итераций, 256-битный hash. Хеширование в отдельном потоке.
- UDP discovery, авторитетный сервер, ограниченные бинарные сообщения, snapshot 20Hz, simulation 30Hz.
- FPS 20/30/60, отключение studs и 20 FPS по умолчанию для ULTRA LOW, предупреждение о ботах.

## Честные ограничения первого этапа

Это ранний технический playable milestone, **не законченная реконструкция**. Точность старого UI и физики требует визуального сравнения и настройки на устройстве.

- Нет измерений FPS/RAM и физического запуска на Lenovo A319. `minSdk=16`, API lint и проверка манифеста не заменяют такой тест.
- APK не содержит JNI/.so: Java/Dalvik-код не привязан к ABI и может выполняться на ARMv7. Это не нативный ARMv7 benchmark.
- Tiny LLM **не включена и не заявляется работающей**. Интерфейс `LLMBackend` — лишь точка расширения. CLASSIC не загружает модель.
- Нет всех 11 катастроф, оригинальных карт, RBXL/RBXLX-импорта, moving platforms, seats, tools, joint destruction и полноценной динамической физики.
- `Part` задаёт будущие shape/material/rotation поля; текущий физический движок обрабатывает только axis-aligned Block. Не считать наличие enum реализацией всех форм.
- Граф размечен для встроенной карты. Самостоятельной генерации navmesh и обхода произвольных препятствий пока нет.
- UI остальных пяти языков пока английский; ответы ботов локализованы на все семь. Языковые файлы ещё не подключены.
- Нет отдельного Bot Manager, редактора внешности, сохранения статистики/персонажа, выбора сложности, полноценного инвентаря и всех графических пресетов.
- Локальная авторизация защищает вход **на устройстве**. LAN сервер доверяет присланному имени и не проверяет пароль другого устройства. Канал LAN не зашифрован. Не публикуйте порт в интернет.
- TCP snapshot без интерполяции может выглядеть менее плавно на удалённом клиенте.

## Сборка

JDK 17 + Gradle 8.9 + Android SDK 35 / Build Tools 34.0.0. Android Gradle Plugin 8.7.3. Gradle wrapper пока не включён; Actions устанавливает указанную версию Gradle.

```
gradle :android:assembleDebug :android:lintDebug :server:distZip :server:distTar
```

Workflow проверяет **фактический APK** через aapt (`sdkVersion:'16'`) и `apksigner --min-sdk-version 16`, а также NewApi/InlinedApi lint. Публикует три запрошенных артефакта.

Проверка ядра без Android SDK:

```
mkdir -p test-build
javac -encoding UTF-8 -source 8 -target 8 -d test-build core/src/main/java/lan/classic/*.java tests/CoreTest.java
java -cp test-build CoreTest
```

См. [архитектуру](docs/ARCHITECTURE.md) и [проверку на устройствах](docs/DEVICE_TEST.md).
